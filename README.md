# akno-web-plus

Site vitrine AKNO — agence web sur mesure (Next.js 16, App Router, Tailwind v4).

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Variables d'environnement

Copier `.env.example` vers `.env.local` et définir `NEXT_PUBLIC_SITE_URL`.

## Scripts

- `npm run dev` — serveur de développement
- `npm run build` — build production
- `npm run start` — serveur production
